description: walk the user through a specific part of the code.
argument-hint: 'this file | module'
disable-model-invocation: true
---

Walk me through a specific part of the code. Don't explain the whole codebase or part of the codebase in one go.

Instead, explore the codebase and build a graph of the relevant modules of the part of the code I am trying to understand. Explain to me the modules from top to bottom using the project's domain glossary vocabulary. After explaining each module, STOP and ask me to make sure I understand each module and how they interact with each other.
